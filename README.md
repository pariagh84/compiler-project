# تحلیل‌گر B-Minor

فاز اول پروژهٔ طراحی کامپایلر؛ تحلیل کد B-Minor و نمایش رنگی ساختار آن با C++17.

کد ورودی ابتدا به توکن تبدیل می‌شود، سپس Parser درخت نحو انتزاعی را می‌سازد. رنگ‌آمیز از توکن‌ها برای تشخیص کلمات کلیدی، نوع‌ها و ثابت‌ها و از AST برای تشخیص نام تابع در اعلان و فراخوانی استفاده می‌کند.

### قابلیت‌ها

- تشخیص توکن‌ها با حفظ متن اصلی و موقعیت خط و ستون
- تحلیل اعلان‌ها، توابع، آرایه‌ها، عبارت‌ها و دستورهای کنترلی
- رعایت تقدم و جهت گروه‌بندی عملگرها
- گزارش خطاهای لغوی و نحوی و ادامهٔ تحلیل پس از خطا
- خروجی رنگی ترمینال و HTML مستقل
- نمایش توکن‌ها و AST برای بررسی نتیجهٔ تحلیل

### ساختار

| بخش | مسئولیت |
|---|---|
| `src/lexer.*` | خواندن ورودی و تولید توکن‌ها |
| `src/parser.*` | تحلیل نحو و بازیابی خطا |
| `src/ast.*` | ساختار درخت و نمایش آن |
| `src/highlighter.*` | تعیین نقش نحوی و تولید خروجی رنگی |
| `src/token.hpp` و `src/diagnostic.hpp` | اطلاعات توکن، موقعیت و خطا |
| `src/main.cpp` | دریافت فایل و انتخاب خروجی |
| `tests/` | آزمون ورودی‌های معتبر، نامعتبر و حالت‌های مرزی |
| `samples/` | نمونه‌های کد B-Minor |
